# Documentation

The project documentation, built with [MkDocs](https://www.mkdocs.org/) and the
[Material](https://squidfunk.github.io/mkdocs-material/) theme.

```sh
cd documentation
python -m venv .venv
.venv/Scripts/activate          # Windows (Git Bash: source .venv/Scripts/activate)
# source .venv/bin/activate     # macOS / Linux
pip install -r requirements.txt

mkdocs serve                    # live preview on http://127.0.0.1:8000
mkdocs build                    # static site in documentation/site/
```

Port 8000 is also Traefik's port in the Docker stack. If the stack is running, use
`mkdocs serve -a 127.0.0.1:8100`.

Pages live in `docs/`; the navigation is in `mkdocs.yml`. `strict: true` makes the
build fail on broken links, so run `mkdocs build` before committing.

## Architecture video

`docs/assets/videos/architecture-overview.mp4` (embedded on the Architecture page) is rendered from
`video/architecture.html`, a scripted SVG animation. Open the HTML in a browser to watch it
interactively (space pauses, the bar seeks). After editing it, re-render:

```sh
cd documentation/video
npm install          # playwright-core + ffmpeg-static; uses your installed Chrome or Edge
npm run render       # writes ../docs/assets/videos/architecture-overview.mp4 (~12 min)
npm run render -- --stills 15,45,77   # PNG stills of chosen seconds, for a quick check
```

The narration script is `video/narration.json`. After editing it, regenerate the clips, then render:

```sh
cd documentation/video
python -m venv .venv-tts && .venv-tts/Scripts/python -m pip install edge-tts
.venv-tts/Scripts/python voiceover.py   # writes vo/*.mp3 and vo/timing.json
npm run render                          # mixes the voice in; sections stretch to fit it
```

`voiceover.py` sends the script text to Microsoft's online speech service (edge-tts). The
renderer slows each captioned section of the animation so it lasts as long as its narration.
`npm run render -- --no-voice` renders the silent version at the original pace.

The background music (`video/music/bed.wav`) is an original track generated by `video/music.py`,
so it has no licence attached. Its layers and level follow the scenes (quiet title, busiest during
scaling, calm at the end), using the narration timeline. It plays about 15 dB under the voice and ducks while
the narrator speaks. To change only the audio without re-rendering every frame:

```sh
.venv-tts/Scripts/python music.py        # regenerate the music bed (after any narration change)
npm run render -- --remux                # rebuild the audio track of the existing MP4 (~20 s)
npm run render -- --remux --music my-track.mp3 --music-db -20   # use your own track instead
```
